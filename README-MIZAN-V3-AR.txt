ميزان MIZAN — نموذج تطوير رقم 3

محتويات الحزمة:
- index.html: واجهة النظام مع دعم تعديل الموكلين والقضايا والأتعاب والجلسات، إضافة إلى المهام.
- manifest.webmanifest: تعريف تطبيق الويب.
- service-worker.js: تخزين الملفات الثابتة مؤقتًا.
- mizan-logo.png: شعار ميزان المستخدم في رأس الواجهة.
- icon-192.png و icon-512.png: أيقونات التطبيق.

ما تغير في هذه النسخة:
1. إضافة زر تعديل إلى الموكلين والقضايا والأتعاب والجلسات.
2. حفظ التعديل على السجل نفسه بدل إنشاء سجل مكرر.
3. إظهار زر إلغاء/سجل جديد لإلغاء وضع التعديل.
4. منع حذف موكل ما دامت هناك قضايا مرتبطة به، ومنع حذف قضية مرتبطة بأتعاب أو مواعيد أو مهام، لتقليل فقد الروابط بين السجلات.
5. الحفاظ على مفتاح التخزين المحلي الحالي mizan_local_v1 ومجموعات البيانات الأساسية.

التحقق المنفذ:
- فحص صياغة JavaScript المضمنة باستخدام Node.js: ناجح.
- فحص صياغة service-worker.js: ناجح.
- فحص manifest.webmanifest كـ JSON: ناجح.

القيود:
- لم يجر اختبار شامل داخل متصفح أو هاتف فعلي.
- التخزين ما زال محليًا في المتصفح ولا توجد مزامنة بين أجهزة أو حسابات مستخدمين.
- لا تستخدم بيانات موكلين حقيقية قبل إجراء اختبار يدوي شامل للإنشاء والتعديل والحذف والنسخ الاحتياطي والاستعادة.
- هذه الحزمة غير منشورة تلقائيًا على GitHub؛ يلزم رفعها يدويًا إلى المستودع المقصود.
